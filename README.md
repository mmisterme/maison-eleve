# Maison Élève

A contemporary fine-dining restaurant website concept, created as Portfolio Project 01.

## About

Maison Élève is a fictional restaurant concept focused on refined cuisine, intimate hospitality and an elegant dining atmosphere.

The website presents the restaurant's identity, menu highlights, dining experience, gallery, reservation demonstration and contact information.

## Built With

- HTML5
- CSS3
- JavaScript

## Features

- Responsive website layout
- Restaurant homepage and navigation
- Menu preview
- Image gallery
- Reservation form demonstration with client-side validation
- Location and contact section

## Running Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Status

Completed as a front-end portfolio concept. The reservation form is a demonstration and does not process real bookings.
